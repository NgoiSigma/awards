# Confirmed awards

Only confirmed, publicly announced award entries belong here.

No live batches exist yet. Create a dated batch such as `2026-01/` only when verification is complete, recipients have provided written confirmation, the contribution role's 14-day public review has ended with no unresolved objections, and the award is publicly announced.

Follow the [award process](../docs/award-process.md) for submission, claims,
candidate publication, objections and payment.

Mathematical solution and Lean formalization use separate contribution records,
so a confirmed role can enter its award batch while the other remains a candidate.
Move each record with its stable ID and retain its public-review dates. After
announcement, send prize money and a medal and confirm delivery; payment and
delivery details are exchanged only by email to **thejustinsunprize@hejustinsun.com**.

Each batch has `batch.yaml`. Each award directory contains `award.yaml`, English `citation.md` and `recipients.md`, and `verification/record.yaml`; a formal claim additionally requires `verification/statement.yaml`.

See the [record guide](../docs/records.md). Use [templates](../docs/templates/) outside this live directory for examples.
