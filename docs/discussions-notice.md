# Discussions notice

Discussions is for general questions and conversation. For challenges to a public candidate or announced award, including proof, priority, identity or eligibility objections, use the [dispute form](../.github/ISSUE_TEMPLATE/dispute.yml). Use the [Correction issue form](../.github/ISSUE_TEMPLATE/correction.yml) for ordinary record corrections. Proposed replacement proofs or catalog updates use the [normal PR template](../.github/PULL_REQUEST_TEMPLATE.md) and link the related issue. See the [award process](award-process.md).

Recommendations and corrections use their corresponding issue forms. Do not publish private information.
